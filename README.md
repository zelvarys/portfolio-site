Zelvarys — Portfolio

A single-page portfolio for Victor Onyemaechi, built with React, TypeScript and Vite.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/App.tsx` — the single page composition
- `src/components/home/` — page sections
- `src/components/layout/` — header and footer
- `src/components/ui/` — shared UI pieces
- `src/content/` — all portfolio copy and data
- `src/index.css` — Tailwind entry and page styles
- `public/` — images, icons, fonts, videos and CV
